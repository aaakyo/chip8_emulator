# CHIP8 emulator
## A CHIP8 emulator made in C using SDL3
This emulator was made as a summer project to solidify my knowledge of the CPU's fetch-decode-execute cycle, biswite instruction decoding as well as to learn how to use libraries such as SDL3 to show graphics on screen and let the user 
interact with the program.

## Key freatures

- **Full instruction set implemented:** Able to run any CHIP8 ROM.
- **SDL3 rendering:** Scaled 64x32 monochrome display.
# Controls

The original 4x4 CHIP-8 hex keypad is mapped to modern QWERTY keyboard layouts:

| CHIP-8 Keypad | QWERTY Mapping |
| :---: | :---: |
| `1` `2` `3` `C` | `1` `2` `3` `4` |
| `4` `5` `6` `D` | `Q` `W` `E` `R` |
| `7` `8` `9` `E` | `A` `S` `D` `F` |
| `A` `0` `B` `F` | `Z` `X` `C` `V` |
